Puli · User’s Guide

Writing notes.

How to write a note, format it, add images and PDFs, change it later, and print it.

Write a note

A new note starts with a title. The cursor sits on the first line, in a heading’s type, after a faint #. Type the title, press ↩, and write the rest.

Today’s date shows in small gray text above the title. It isn’t part of the note’s text. When you edit an older note, you see the day you first saved it.

To start the note as body text instead of a title, press ⌫ at the start of the title line. The # goes away.

Save it

Choose File › Save, or press ⌘S. The note is saved, and you keep writing it.

Puli also saves the note when you leave it: when you choose New Note, open another journal, choose Tasks or Tags from the View menu, switch to another app, or quit. Pausing while you type, or clicking in the context pane, doesn’t save it.

A note with nothing in it isn’t saved. A new note you leave with only its # isn’t saved either. If you delete all the text of a saved note and save it, the note is removed from the journal.

The saved message

When you save, you see “Saved” at the bottom of the window. It fades after 3 seconds. If saving created people, groups, or projects, or found tags to check, it says so: “Saved · 1 entity created · 1 tag to check”. See People, groups, and projects for what those mean.

Change an earlier note

Open a note in the editor in any of these ways:

  • Click it in the list of notes.
  • ⌘-click it on a person’s, group’s, or project’s page in the context pane.
  • On the note’s page in the context pane, choose Edit from the ⋮ across from its date.

If you were writing a note you hadn’t saved, Puli saves it first. Your changes go into the same note, which keeps the date you first wrote it.

A note’s page in the context pane shows the note as the editor does, with its date at the top. You can select and copy from it, tick its tasks, and click its tags, but you can’t type into it.

Format text

Puli’s notes are Markdown. You type the marks, and Puli hides them once the cursor moves away. Put the cursor back on the text and the marks show again, faintly, so you can change them.

  • **Strategy** for bold, or select the text and press ⌘B.
  • *Strategy* or _Strategy_ for italics, or ⌘I.
  • `budget.xlsx` for code, or ⌘E.
  • ~~Friday~~ to strike text through.
  • ==outcomes== to highlight it, or ⇧⌘H.

Press the same keys again to take the marks off. These commands are also in the Format menu.

Headings

Type # and a space at the start of a line for a heading, ## for a smaller one, and so on. A heading’s #s show faintly while the cursor is on its line.

Code blocks

Put ``` on a line before the code and on a line after it. You can use ~~~ instead. Everything inside shows as written, in a monospaced font. Tags and formatting in a code block aren’t read.

Lists

  • Start a line with -, *, or + and a space for a bullet.
  • Start it with 1. or 1) for a numbered list.
  • Start it with - [ ] for a task. See Tasks and promises.

Press ↩ at the end of an item to start the next one. Numbers count up for you. Press ↩ on an empty item to end the list. Press ↩ in the middle of an item to split it in two.

Press ⇥ (tab) anywhere in an item to indent it one level, and ⇧⇥ to bring it back.

Quotes

Start a line with > and a space. The line shows with a bar down its left. Press ↩ to continue the quote, and ↩ on an empty quote line to end it. Use >> for a quote inside a quote. A quote can hold bullets and numbered lists.

A checkbox in a quote is only a picture of one. It doesn’t tick, and it isn’t a task.

Horizontal rules

Type --- on a line of its own for a thin line across the note. *** and ___ work too.

Links

Web addresses that start with https:// become links as you type them. Click a link to open it in your browser.

  • To link words, select them and paste a web address over them. Puli writes [the plan](https://example.com/plan) and shows “the plan”, underlined.
  • Or select the words and press ⌘K (Format › Link), then type the address.
  • For an email address, write <diane@example.org>. Clicking it opens a new email in your mail app.

A bare example.com or diane@example.org, without the https:// or the angle brackets, isn’t a link.

Keep a mark as written

Put a backslash before a mark to show it as plain text. \*not italic\* shows “*not italic*”. \#Grant-Report shows “#Grant-Report” and isn’t a tag. \- Not a bullet isn’t a bullet. The backslash shows faintly while the cursor touches it.

A backslash before anything else is just a backslash, so C:\Users\diane shows as written.

Images and PDFs

Drop an image or a PDF into a note, or paste one. It goes on a line of its own where the cursor is, and it’s kept in the journal, encrypted with your notes. If you back the journal up to iCloud, it goes with your notes.

  • An image shows at its own size, never wider than the text.
  • A PDF shows as an icon, with its name beneath.
  • Double-click an image to open it in Quick Look. Double-click a PDF to open it in Preview, or whichever app opens PDFs on your Mac.

An image moves as one piece. Click it to select it. Press ⌫ after it, or ⌦ before it, to remove it. Undo brings it back.

Puli doesn’t load images from the web. A web address for an image shows as a link. If a note names a file the journal doesn’t have, you see its name and “Missing”.

A PDF bigger than 250 MB stays on this Mac and isn’t backed up to iCloud.

Find in a note

Choose Edit › Find › Find…, or press ⌘F. Type what you’re looking for. Every match is outlined, with the one you’re on in yellow.

  • ↩ goes to the next match, and ⇧↩ to the one before.
  • ⌘G and ⇧⌘G do the same, with the find bar open or closed.
  • Tick Replace to replace a match, or every match.
  • ⎋, or Done, closes the find bar.

While the find bar is open, tags show as you wrote them, like @Grace-Liu, because Find looks at the note as written. Search for “Grace-Liu”, not “Grace Liu”. To search every note, see Finding your notes.

Print a note

Choose File › Print…, or press ⌘P. Puli prints the note in the editor, or the one you chose in the list of notes. To save it as a PDF, use the PDF menu in the Print dialog.

The printed page shows the note’s date, then the note, as Puli shows it, on white paper, even in dark mode. Tags print as names, in their colors.
