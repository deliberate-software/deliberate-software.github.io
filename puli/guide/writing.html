Puli · Handler’s Guide

Writing notes.

How to write a note, format it, add tables, links, and pictures, change it later, and print it.

Write a note

Choose File › New Note, or press ⌘N. The first line is the note’s title. Press ↩ and write the rest.

Today’s date shows above the title. It isn’t part of the note.

Save it

Choose File › Save, or press ⌘S. Puli also saves a note when you leave it: when you start another note, open a different one, switch apps, or quit.

You see “Saved” at the bottom of the window. If saving added someone new to the journal, it says so: “Saved · 1 entity created”.

Change an earlier note

Click a note in the list of notes, or on a page in the context pane, to open it in the editor. Your changes go into the same note, which keeps the day you first wrote it.

Format text

Use the Format menu, or its keys:

  • Bold ⌘B, Italic ⌘I, Strikethrough ⇧⌘X, Highlight ⇧⌘H, and Code ⇧⌘C.
  • Title ⌥⌘1, Heading ⌥⌘2, Subheading ⌥⌘3, and Body ⌥⌘0.
  • Quote ⌘', Code Block ⌥⌘C, and Divider.

Puli’s notes are Markdown, so you can also type the marks, such as **bold** or # Heading. Puli hides them once the cursor moves away.

Lists

Start a line with - and a space for a bullet, 1. for a numbered list, or [] for a task. Or choose Bulleted List ⇧⌘8, Numbered List ⇧⌘7, or Task ⌃⌘T from the Format menu.

Press ↩ for the next item, and ↩ on an empty one to end the list. Press ⇥ to indent an item, and ⇧⇥ to bring it back.

For more on tasks, see Tasks and promises.

Tables

Choose Format › Table, and type the first column’s name. Press ⇥ to go to the next cell, and ⇧⇥ to go back. ⇥ in the last cell adds a row. Press ↩ in the last row to leave the table.

Links

A web address that starts with https:// becomes a link as you type it. To link words, select them and paste an address over them, or press ⌘K and type the address. Click a link to open it.

Images and PDFs

Drop an image or a PDF into a note, paste one, or choose Format › Attach Image or PDF… ⇧⌘A. It’s kept in the journal with your notes. Double-click it to open it.

Paste from other apps

Text you paste from a web page, Mail, Google Docs, or Word keeps its headings, lists, bold, and links. A checklist becomes tasks. To paste plain text, choose Edit › Paste and Match Style, or press ⌥⇧⌘V.

Dictation

Choose Edit › Start Dictation, or press the Dictation key, and say what you’d write. Say “new line” to start the next item in a list, and “new paragraph” to end the list.

Notes from anywhere

You don’t have to be in Puli’s window to start a note or add a task:

  • Click the dog in the menu bar, and choose New Note or Add Task.
  • Add Puli’s widget to your desktop, and click New Note or Add Task.
  • Ask Siri: “New note in Puli” or “Add a task in Puli”.
  • Select text in another app, right-click it, and choose Services › New Puli Note with Selection, or Add Selection to Puli as Tasks.

A task you add this way goes in today’s note, under Tasks.

Find in a note

Choose Edit › Find › Find…, or press ⌘F. Press ↩ or ⌘G for the next match, and ⇧⌘G for the one before. To search every note, see Finding your notes.

Delete a note

Choose Edit › Delete Note, or select the note in the list of notes and press ⌘⌫. It goes to the Trash, and ⌘Z brings it back. To see the Trash, choose View › Trash.

The Trash empties itself after 30 days. You can change that in Settings › General.

Print a note

Choose File › Print…, or press ⌘P. To save the note as a PDF, use the PDF menu in the Print dialog.
