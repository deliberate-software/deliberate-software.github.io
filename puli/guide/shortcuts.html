Puli · User’s Guide

Keyboard shortcuts.

Puli’s keys, in one place. For a short list inside Puli, choose Help › Navigation.

Journals

  • ⌥⌘N New Journal…
  • ⌘O Open Journal…
  • ⇧⌘J Manage Journals…
  • ⌘W Close Journal
  • ⌥⌘L Lock Journal
  • ⌘, Settings…

Notes

  • ⌘N New Note
  • ⌘S Save
  • ⌘P Print…
  • ⌘⌫ Delete Note, from the list of notes
  • ⌘Z Undo, and ⇧⌘Z Redo

Writing

  • ⌘B Bold, ⌘I Italic, ⇧⌘X Strikethrough, ⇧⌘H Highlight, ⇧⌘C Code
  • ⌥⌘1 Title, ⌥⌘2 Heading, ⌥⌘3 Subheading, ⌥⌘0 Body
  • ⇧⌘8 Bulleted List, ⇧⌘7 Numbered List, ⌃⌘T Task
  • ⌥⌘] Indent, ⌥⌘[ Outdent, or ⇥ and ⇧⇥ in a list
  • ⌘' Quote, ⌥⌘C Code Block
  • ⌘K Link
  • ⇧⌘A Attach Image or PDF…
  • ⌥⇧⌘V Paste and Match Style
  • ⇥ and ⇧⇥ Next and previous cell, in a table

Finding

  • ⌥⌘F Search every note
  • ⌘F Find in the note
  • ⌘G Find Next, and ⇧⌘G Find Previous
  • ⌘E Use Selection for Find

Views

  • ⇧⌘N Notes
  • ⇧⌘I Tags
  • ⇧⌘D Today, with the Today lesson
  • ⇧⌘T Tasks, with the Tasks lesson
  • ⇧⌘P Progress, with the Progress lesson
  • ⌃⌘G Graph, with the Graph lesson

Moving around

  • ⌥⌘← Previous Pane, and ⌥⌘→ Next Pane
  • ⌘[ Back, and ⌘] Forward
  • ⌃⌘S Show or hide the sidebar
  • ⌃⌘L Show or hide the list of notes
  • ⌘\ Show or hide the context pane
  • ⌥⌘\ Move the context pane to its own window, and back
  • ⇧⌘F Focus
  • ⌘+ Zoom In, ⌘− Zoom Out, ⌘0 Actual Size
  • ⌃↩ Open the menu of what’s selected

In the Tasks view

  • Space Complete the selected task, or reopen it
  • ⌥/ Start the task, or stop it
  • ↩ Open the task’s note
  • ⌥⌘↑ and ⌥⌘↓ Move the task up or down

Suggestions

  • ⌘↩ Accept All, and ⇧⌘↩ Ignore All
