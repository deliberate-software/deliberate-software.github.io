Puli · User’s Guide

Keyboard shortcuts.

Every key Puli knows, in one place. For a short list inside Puli, choose Help › Navigation.

Journals

  • ⌥⌘N New Journal…
  • ⌘O Open Journal…
  • ⌘W Close Journal
  • ⌥⌘L Lock Journal
  • ⌘, Settings…
  • ⌘Q Quit Puli
  • ↑ ↓ Move through the choices in the welcome window
  • ↩ Choose the one selected in the welcome window

Notes

  • ⌘N New Note
  • ⌘S Save
  • ⌘P Print…
  • ⌘⌫ Delete Note, when you aren’t typing in the editor
  • ⌘Z Undo, such as a deleted note
  • ⌘-click a note on a page in the context pane to edit it

The list of notes

  • ↑ ↓ Move through the notes, each opening as you reach it
  • ↩ or ⇥ Put the cursor in the editor
  • ⇧⇥ Go to the cabinet
  • ⌫ Move the note to the Trash
  • ⌃↩ Open the note’s menu

Writing

  • ⌘B Bold
  • ⌘I Italic
  • ⌘E Code
  • ⇧⌘H Highlight
  • ⌘K Link
  • ↩ At the end of a list item, task, or quote, start the next one
  • ⇥ Indent a list item or task
  • ⇧⇥ Take the indent away
  • ⌘Z Undo
  • ⇧⌘Z Redo

Finding in a note

  • ⌘F Find…
  • ⌘G Find Next
  • ↩ Next match, in the find bar
  • ⇧↩ The match before, in the find bar
  • ⎋ Close the find bar

Tags

While you type a tag and see suggestions:

  • ↓ Highlight the next suggestion
  • ↩ Choose the highlighted suggestion
  • ⇥ Choose it, and add a space after it
  • ⎋ Close the suggestions, keeping what you typed

In the Tags view:

  • ↑ ↓ Move through the list
  • ↩ Show the selected page in the context pane
  • ⌫ Move the selected person, group, or project to the Trash
  • ⌃↩ Open its menu

Context

  • ⌘\ Show or hide the context pane
  • ⌥⌘\ Move Context to Its Own Window, or Move Context Back

Tasks

  • ↑ ↓ Move through the tasks
  • Space Tick the selected task, or untick it
  • ⌥/ Start the selected task, or stop it
  • ↩ Show the task’s note in the context pane
  • ⌘↩ Edit the task’s note
  • ⌃↩ Open the task’s menu
  • ⎋ Stop editing a task in place, leaving it as it was
  • ⌥-click a checkbox to start a task, or stop it
  • ⌘-click a task to edit its note
  • Option-click a group’s heading to collapse or open every group

Moving around

  • ⌥⌘F Search
  • ↓ From Search, go to the first match
  • ⎋ In Search, clear it
  • ⌘[ Back
  • ⌘] Forward
  • ⌃⌘S Show or hide the sidebar
  • ⌃⌘L Show or hide the list of notes
  • ⇧⌘F Focus, or Leave Focus
  • ⌃↩ Open the menu of what’s selected

In the cabinet:

  • ↑ ↓ Move through the views and names, each showing as you reach it
  • ← Fold a section or project
  • → Open it again
  • ⇥ or ↩ Give the keys to the view showing

Views

  • ⇧⌘N Notes
  • ⇧⌘T Tasks
  • ⇧⌘I Tags
  • ⇧⌘B Board, once your journal has stages
  • ⇧⌘G Graph, a lesson
  • ⌘+ Zoom In
  • ⌘− Zoom Out
  • ⌘0 Actual Size

The Trash

  • ↑ ↓ Move through the Trash
  • ↩ Restore the selected item
  • ⌘⌫ Delete Now, after asking
  • ⌃↩ Open its menu

The Graph

The Graph is a lesson. See The graph.

  • ← → ↑ ↓ Move the ring from dot to dot
  • ↩ Center the ringed dot and show its page
  • + − Zoom in or out
  • ⎋ Clear the filter, then the centered dot
